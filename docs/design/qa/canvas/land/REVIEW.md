### **Review (Codex, round 1)**

- `src/data/land/s2Math.ts:38` · major · The Earth Search flag has the wrong polarity in the metadata fallback, and the explicit metadata path trusts an asset offset even when it conflicts with that flag. The recorded fixture itself has `earthsearch:boa_offset_applied: true` and `offset: -0.1`. Subtracting twice inflates NDVI on harmonized assets, and clamping can move an otherwise valid red DN below 1000 to zero. With harmonized red/NIR DNs of 1400/3600, the code produces 0.733 instead of 0.44. · Resolve the offset for the actual COG representation, verify contradictory metadata against a reference COG/product pair, and skip ambiguous observations if the representation cannot be established. Test pre-PB04, raw PB04, already corrected PB04, and the conflicting fixture against independently expected reflectance and NDVI. [Earth Search collection notes](https://github.com/Element84/earth-search/blob/main/docs/collections/sentinel-2-l2a.md), [Earth Search offset reports with COG-to-product comparisons](https://github.com/Element84/earth-search/issues/71).
- `src/data/land/satellite.ts:34` · major · The COG window is aligned to UTM grid north, but `nearAt` and `computeCoverMeans` (`sampleLand.ts:51`) index it as true north in a lat/lon approximation. At the recorded fixture site, about 1.36° of convergence displaces the 5 km edge by about 118 m, larger than a cell. Mosaics spanning zones can compound the error. The mock at `s2Math.test.ts:88` ignores the requested window and cannot detect it. · Persist the grid transform and reuse it in both sampling directions, or resample each item into one shared metric grid. Use the same footprint for the STAC query and add an offline fixture whose value changes across a georeferenced cell boundary away from the centre.
- `src/data/land/satellite.ts:136` · major · Only the first item's date is tried. A newer footprint that only clips the window, a locally cloudy acquisition, or missing COGs can discard a usable older acquisition. An all-zero grid is returned and cached as fresh for five days, and one failed required band aborts the entire same-day mosaic. Also, the first item's sun angles are attached to cells supplied by other items. · Try bounded acquisition groups newest-first, continue past unusable items, require usable local coverage before caching, and associate solar geometry with the contributing acquisition. Test a failed or cloudy newest item followed by usable data, and two adjacent granules with different angles.
- `src/data/land/useLand.ts:32` · major · The hook loads the default ±6 km, Israel-only WorldCover collection for a ±60 km far grid. Beyond the loaded tiles, the sampler either calls unknown cover class 0 a per-cover match to other unknown cells, or assumes grass when the loader returns null (`sampleLand.ts:61,95,100`). Far land therefore loses the WorldCover class and often the promised Sentinel‑2 cover-mean fallback. · Load WorldCover for the sampled footprint at a suitable resolution, propagate the actual class through the sampler, and represent out-of-coverage cells explicitly. Exclude unknown classes from observed cover means. Test both gaps between loaded tiles and a far point with a known class.
- `src/data/land/gibs.ts:51` · major · GIBS can reply HTTP 200 with a blank tile. The fetcher accepts that date when any tile merely decodes, even if the entire requested footprint is nodata. A single failed HTTP tile discards the other usable tiles. A thrown NDVI fetch or decoder error discards successful RGB, and `!ndviSet` also discards RGB when only its layer is available. · Check validity within the sampled footprint, retain valid partial tiles with holes, and retry or fall back independently for each layer. Test blank 200s, one missing tile and RGB-only success. [NASA GIBS WMTS response codes](https://github.com/nasa-gibs/onearth/wiki/WMTS-Response-Codes).
- `src/data/land/sampleLand.ts:131` · major · The shared date is taken from the first available grid even when individual values come from different sources. The existing far fixture has RGB dated November 1 and NDVI November 18, yet the shared date says November 18, understating RGB age by 17 days. A missing NDSI also carries a climatology source even though climatology emits no NDSI. · Tie the observation date to each resolved value, represent missing NDSI explicitly, and test mixed near/far/mean/climatology results before Stage 2 applies age blending.
- `src/data/land/sampleLand.ts:84` · major · A positive green/SWIR ratio alone is treated as a calibrated snow probability. Open water is admitted by SCL and can reach the top of the ramp because its SWIR reflectance is low. A class mean also exports near-window snow conditions to elevations where the same cover has different snow cover. · Aggregate SCL class 11 among valid land samples as observed snow fraction, or use an explicit water and brightness screen with NDSI. Use elevation-aware climatology for distant cells lacking snow evidence. Add mixed snow/land and water cases. [Sentinel‑2 L2A snow detection algorithm](https://sentinels.copernicus.eu/documents/247904/446933/Sentinel-2-Level-2A-Algorithm-Theoretical-Basis-Document-ATBD.pdf).
- `src/data/land/recentWeather.ts:72` · major · With `forecast_days=1`, the fixture's 61st day is today and contains a full forecast-day sum. The tail slices include today's forecast and omit the oldest completed day in every window. Missing precipitation is also converted to zero at line 56, so a response containing only a time axis can yield maximum dryness tagged Open-Meteo. `precipitation_sum` includes snowfall, but the threshold is described as days since rain and the dryness calculation credits it as immediate recharge. · Select completed local dates, preserve gaps and report usable coverage, and use liquid rain plus showers for recharge or model snow separately. Add exact assertions for an end-of-window rain pulse, rain forecast later today, and a missing series. [Open-Meteo daily variable definitions](https://open-meteo.com/en/docs#daily=precipitation_sum).
- `worker/src/routes.ts:89` · major · The new 60-day cap applies to every allowed forecast field combination. The lightweight handoff payload describes one request shape, but the same endpoint now permits 67 days of hourly data for 20 fields across two models, over 64,000 hourly values, with responses buffered and cached as text. This expands upstream quota and Worker payload for every supported origin. · Keep the existing limit for general forecasts and admit the 60-day window only on the narrow land-weather query shape or its own route. Test rejection of the expanded hourly combination. [Open-Meteo API call accounting](https://open-meteo.com/en/pricing).
- `src/data/land/climatology.ts:59` · major · The fallback ignores longitude and uses latitude and elevation alone as a regional rainfall classifier. It produces the same Mediterranean winter-rain curve for coastal California and the Atlantic coast of the southeastern US at the same latitude and altitude. Cold also implies persistent snow even in dry conditions. The cited Köppen–Geiger and MODIS products supply no values to these calculations, leaving thresholds and cover profiles without a reproducible derivation. · Use a compact coordinate-indexed classification or monthly normals sampled from a documented source, account for precipitation in the snow fallback, and label any heuristic parameters as such. Test opposite seasonal rainfall regimes at matched latitude and elevation. [Beck et al. climate classification data](https://repository.library.noaa.gov/view/noaa/64819).
- `src/data/land/s2Math.ts:101` · minor · The SCL-valid fraction can be high even if each spectral index is supported by very few valid band pairs. A black RGB patch also suppresses usable spectral indices entirely. Since the mask is applied at the overview resolution, coverage refers to accepted overview samples, and independently averaged spectral overviews can mix cloudy and clear native pixels. · Track support per measurement and let RGB and spectral indices fall back independently. Document the verified COG resampling semantics or apply SCL on the common native grid before aggregation. Test SCL-valid pixels with band nodata.
- `src/data/land/landCache.ts:144` · minor · Weather freshness is anchored to local insertion. A Worker `STALE` response can be up to 12 hours old and is immediately promoted to another six hours of fresh cache. The hook checks freshness only when its effect runs, so an open view can retain weather past both limits. · Use the upstream timestamp for freshness, define a weather-specific stale limit, and recheck on focus or at expiry. Test a stale upstream response and an expired active entry.
- `src/data/land/landCache.ts:75` · minor · IndexedDB lookup success returns null on a missing key even if an earlier write failed and the memory store has the value. Failed writes also leave an older IndexedDB hit ahead of a newer in-memory value. Every write duplicates the payload in an unbounded memory map, and an IndexedDB open blocked by an upgrade can hold up all three remote refreshes. · Make the memory fallback authoritative for failed writes, bound retained entries, and handle a blocked database open or transaction abort. Exercise these paths with offline storage doubles.

This leaves the production assumption that an index is the same as the published palette reference untested on an actual GIBS tile, including the blank-tile case. · Keep a small genuine indexed response or a lossless crop preserving its palette and transparency, and assert known pixel values independently of the production mapper. [NASA MODIS NDVI palette](https://gibs.earthdata.nasa.gov/colormaps/v1.3/output/MODIS_NDVI.html).
- `src/data/land/sampleLand.ts:96` · minor · Sampling eagerly computes climatology, allocates near and far results, and triggers the 2,500-cell cover scan on the first call for a new grid, even when the requested values resolve directly. It also recalculates place-wide weather dryness for every point. The hook has no production consumer yet, so this cost is absent from current scrub and paint benchmarks. · Prepare source-wide values when land data changes, compute fallbacks on demand, and measure the integrated Stage 2 sampler with the scrub runner.
