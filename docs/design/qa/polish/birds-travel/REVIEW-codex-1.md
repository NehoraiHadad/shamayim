# Birds travel review

Reviewed `b2e250d..e5b1f78` on `claude/fix-birds-travel`, including `4f05e9e`, `bcbad4b`, and `e5b1f78`.

## Findings, highest severity first

1. **P1 · Flocks can appear at full opacity on a minute update.** `src/world/lifeSchedule.ts:570`, `src/world/lifeAhead.ts:14`, `src/scene/model/continuity.test.ts:66`, `src/scene/model/continuity.test.ts:94`. A flock enters the model only if it is active at the minute being built. Look-ahead advances flocks already in the model, so the compositor has no layer to fade in for a flock that starts later in the minute. In the Haifa fixture, `2026-11-17:bat:15` starts at **17:09:26**. The 17:09 model has no layer for it, and the 17:10 model shows three bats at **0.99999 opacity and 0.999 scale**, around `(326, 289)`, 110 px above the terrain crest. The `fromStart` exemption accepts this exact jump. It estimates reach from the laid 3D closest distance, while the actual fade uses distance over the ground. Include starts that fall inside the rendered interval, with zero opacity before departure from the start of the track, and test both sides of the minute boundary at the same physical time.

2. **P2 · A fast flock translates with a stale facing direction until the next rebuild.** `src/scene/model/birds.ts:111`, `src/world/lifeAhead.ts:13`, `src/scene/model/birdFlight.ts:90`. The sprite strip uses the initial heading relative to the observer and the initial elevation for its full lifetime. Its position continues to advance. In Haifa, `2026-11-17:crow:25` at **10:23** flies on a ground heading of about **122°**. Its bearing from the observer changes from **280° to 146°** in 59 s, changing its apparent heading by **133°** from approaching to receding. Layer opacity stays above 0.96 at both samples and the strip keeps its initial yaw. The faster passes expose this even on straight tracks. Carry the viewing orientation through the flight samples and verify the drawn facing during the closest pass.

3. **P2 · Retiming a bent path can materially change the ground speed.** `src/world/lifeSchedule.ts:299`, `src/world/lifeSchedule.ts:318`, `src/world/lifeSchedule.ts:505`, `src/world/lifeSchedule.test.ts:58`. The straight-pass duration is fixed before terrain steering. The laid path then sets the actual horizontal speed by dividing its length by that duration, as prescribed by Brief 2. In the Tel Aviv fixture, `2026-11-17:gull:18` draws **7.75 m/s** and flies **9.99 m/s** (**+29%**) because its route is **9.03 km** over a scheduled **903 s**. Across 1,015 fixture events, five exceeded their draws by over 10% and two by over 25%. The angular test uses the already adjusted speed as its bound, so it cannot catch this drift. Resolve which constraint takes precedence for bent tracks and add an independent speed check.

4. **P3 · Callers can change the cached track or the inputs used on first lay.** `src/world/lifeSchedule.ts:111`, `src/world/lifeSchedule.ts:305`, `src/world/lifeSchedule.ts:322`, `src/world/flightPaths.ts:53`. `lay()` returns the same writable track and typed array indefinitely. In a local probe, adding `100` to `event.lay().track.pts[0]` moved all later `flockAt(event, event.t0)` results 100 m east while leaving the cached closest distance untouched. The event also exposes the same `home` object used by `wayOf`, so edits to it affect steering if made before the first lay and are ignored after it. The height-selection loop reads `ctx.flight` and `ctx.camera` at lay time. Current production callers only read the track, and `flockAt` creates fresh output objects. Keep the mutable cache private and capture the layout inputs when constructing the event.

5. **P3 · The timing test can pass with a cold-start regression or with eager laying.** `src/world/flockLazy.test.ts:15`, `src/world/flockLazy.test.ts:38`, `src/world/flockLazy.test.ts:43`, `docs/design/qa/polish/birds-travel/IMPL-2.md:18`. The gate takes the median of three fresh builders in one process after other world builds. It uses a fixed 1,400 ms ceiling, or 4,200 ms in CI, for Haifa and Shadmot Mehola. For example, the reported Tel Aviv cold run was **833.8 ms vs 695.4 ms** on the base (**+19.9%**), with a separate run at 689.0 ms. The warmed comparison improves, while these cold runs leave the +10% cold target unresolved. Eager laying on a fast machine could also pass the timing and output-equality assertions. Count actual lays before sampling and on repeated sampling, and compare cold starts against the base under the same conditions.

6. **P3 · The motion checks can count invisible travel or pass with no flock measurement.** `src/scene/model/birdsTravel.test.ts:34`, `src/scene/model/birdsTravel.test.ts:40`, `src/scene/model/birdsTravel.test.ts:49`, `src/scene/model/lifeTracks.ts:43`, `e2e/birds.motion.mjs:59`, `e2e/birds.motion.mjs:74`, `e2e/birdMarks.mjs:71`. The model test counts a layer whenever *any* look-ahead pose passes culling. A flock that comes into frame at second 30 can therefore contribute a 0–10 s displacement while both measured poses are offscreen. The browser probe treats tracked image clusters as flocks and exits successfully when there are zero tracks. If the painter stops drawing birds and the crop has no trackable marks, the model still moves, the browser has nothing to assert against, and both checks can pass. The model summary also depends on earlier test cases filling a shared array, so running that case alone fails on an empty sample set. Measure visible intervals, require an identified flock in the pixel check, and make the assertions independent of test execution order.

## Verification

- Ran `lifeSchedule.test.ts`, `flockLazy.test.ts`, `birdsTravel.test.ts`, and `continuity.test.ts` against local fixtures. All **21 tests passed**.
- Probed **1,015** scheduled events using the eight baseline panoramas and the November 17 forecast fixture. The horizontal route is independent of the altitude-selection pass. Both endpoints had zero distance fade in every sampled event. For those tracks, fitting the laid length into the scheduled duration and clamping the look-ahead to `t1` worked as intended. The arrival and heading examples additionally used the world builder and bird layer output.
- Reviewed the browser probe at the committed revision. The browser probe itself was not run. No network service was fetched.
