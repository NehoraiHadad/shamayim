# Shamayim UI sweep (read-only audit)

Scope: `src/ui/`, `src/App.tsx`, `src/scene/react/{SceneOverlay,SceneScrubber,SceneFallback,SceneCanvas}`, `src/text/`, `index.html`, `src/index.css`, `src/ui/tokens.css`, `src/pwa.ts`.
Method: code reading. The bidi claims were verified in headless Chromium on static HTML only (no app, no network). The scratch script is in the session scratchpad `ui\bidi2.cjs`, nothing was written to the repo.

Bidi probe result (RTL paragraph, Chromium, x positions of glyphs): raw `-3°` and raw `−5°` (U+2212) both render visually as `3°-` / `5°−` (sign on the wrong side). Only a `<bdi>` that includes the sign fixes it. Plain `05:40–17:00` renders sunrise on the right; the same text in an LTR `<bdi>` renders sunrise on the left.
